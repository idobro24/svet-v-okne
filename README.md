# Свет в окне

Тихое веб-приложение поддержки для тех, кому сейчас тяжело: после развода, в одиночестве, во время беременности.

Здесь нет ленты, лайков и чужих мнений — только поддерживающие фразы, «погода внутри» с идеями самопомощи, банка хороших моментов, письмо себе в будущее, дыхание с огоньком, треск камина и телефоны, по которым можно позвонить.

Всё, что человек пишет и отмечает, хранится только на его телефоне. Приложение лишь анонимно считает число посещений через GoatCounter — без имён, cookie и личных данных.
